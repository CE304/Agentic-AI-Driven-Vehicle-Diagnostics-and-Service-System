# Contributing

1. Create a branch for each change.
2. Keep credentials and proprietary manuals out of commits.
3. Run `python -m compileall app tests` before opening a pull request.
4. If changing diagnostic rules, describe the technical evidence and the test case.
5. Clearly mark simulated data and do not present it as real repair history.
6. Keep Traditional Chinese user-facing terminology consistent with Taiwan automotive usage.
