# 3D Model Assets

The production prototype can launch an interactive 3D engine-bay/component viewer from the work-order page.

Large GLB/GLTF model assets are not included in this public repository because their source/license and file size must be reviewed separately before redistribution. Place approved model assets here and serve this directory on the configured 3D-preview port (default deployment: 8765).

The application remains usable without the optional 3D viewer; diagnostic, RAG, expert-consultation and work-order functions are independent of these assets.
